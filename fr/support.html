Questions fréquentes

Où sont mes données ?

Sur votre appareil. Si la synchronisation iCloud est activée (Réglages → Synchroniser avec iCloud), elles sont aussi copiées dans votre iCloud privé et apparaissent sur vos autres appareils. Les détails sont dans la politique de confidentialité.

L’app demande-t-elle un compte ?

Non. Cartons n’a pas de connexion.

Le bouton du micro est absent.

Il n’apparaît que pour les langues que le système sait reconnaître sur l’appareil. Réglages → Dictée explique pourquoi il est masqué. La saisie fonctionne toujours.

Comment imprimer une étiquette ?

Ouvrez un carton, touchez l’icône d’imprimante, choisissez la taille et le code (QR, code-barres ou les deux), puis Imprimer ou Exporter en PDF.

Combien de cartons sont gratuits ?

Un projet (archivés compris) et 10 cartons hors projets. Les cartons d’un projet ne comptent pas. Un achat unique supprime les limites.

Comment restaurer un achat ?

Réglages → Restaurer l’achat, avec le compte Apple utilisé pour l’achat.

Comment passer mes cartons sur un nouvel appareil ?

Activez la synchronisation iCloud sur les deux appareils (Réglages → Synchroniser avec iCloud). Vos cartons apparaissent sur le nouvel appareil.
